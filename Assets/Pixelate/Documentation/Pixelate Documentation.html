Pixelate Documentation

Pixelate converts 3D scene objects and animation clips into pixel-art sprite sheets from inside the Unity Editor. This offline document covers the core setup. The hosted docs are the canonical source for screenshots, updates, and detailed troubleshooting.

1. Requirements

Pixelate is an Editor tool. Capture workflows do not require Play Mode.

  • Unity version: any version of Unity 6.
  • Required package: 2D Sprite, package id com.unity.2d.sprite.
  • Recommended workflow: Universal Render Pipeline. Pixelate's demo content is built for URP, and URP supports Sprite-Lit 2D lighting with normal maps out of the box.
  • Export location: generated textures must stay inside the Unity project's Assets/ folder.
Tip: Use an orthographic capture camera for predictable sprite output.

2. Quickstart: capture a static sprite

  1. In the Hierarchy, right-click and select Pixelate > Pixelate Capture Manager.
  2. Select the new Pixelate Capture Manager GameObject.
  3. Drag the GameObject you want to capture into Target.
  4. In Camera, assign the camera that frames the target.
  5. Set Cell Size. The default is 64 x 64.
  6. Use Preview to check framing and draw mode.
  7. In Output, choose a folder under Assets/.
  8. Click Capture.

A static capture creates {TargetName}.png. If Normal Map is enabled, Pixelate also creates {TargetName}_N.png and links it as the diffuse sprite sheet's secondary normal texture.

3. Animation capture

  1. Assign a Target and Capture Camera first.
  2. Turn on the Animation section.
  3. Add one or more Source Clips.
  4. Set Frames Per Second. The default is 12.
  5. If the target has no Animator, click Add Animator in the Animation section.
  6. Click Capture.

Each source clip is captured into its own sprite sheet atlas. If Normal Map is enabled, each clip also gets a matching normal-map atlas linked to its diffuse atlas. If Animation is enabled but no clips are assigned, Pixelate falls back to static image capture.

5. Profiles and palettes

Each Pixelate Capture Manager starts with a local unsaved Pixelate Profile. Use it for per-manager color and lighting settings. Click Save when you want to create a reusable PixelateProfile asset. Click Unlink to copy assigned profile values back into the local manager profile.

Color Palette can be disabled, generated automatically, or driven by a custom 1-pixel-tall palette texture. Invalid custom palettes are ignored and behave like no palette.

6. Normal maps

Enable Normal Map in the local or assigned profile to export matching normal-map atlases. The default Lighting Steps value is 2. During export, Pixelate assigns each generated normal map as the diffuse sprite sheet's _NormalMap secondary texture.

  • URP recommended: use Unity's Sprite-Lit-Default shader with a 2D Renderer and 2D lights.
  • Light 2D setup: turn on Normal Maps on the Light2D component.
  • 2D Renderer setup: under Light Render Textures, set Render Scale to 1.
  • Demo reference: open Assets/Pixelate/DEMO/Scenes/Visualize.unity or use the pre-configured assets in Assets/Pixelate/DEMO/URP.
  • Built-in fallback: use the included toon-lit sprite shader only when the project cannot use URP.

7. Output files

Pixelate exports sliced atlas textures inside the selected Assets folder. Output is grouped under {SelectedExportFolder}/{TargetName}/. Animation clips export under {SelectedExportFolder}/{TargetName}/{ClipName}/.

Pixels Per Unit sets the sprite import scale for generated diffuse and normal-map textures. Pixelate disables Generate Physics Shape on exported sprites.

  • {TargetName}.png: static diffuse sprite sheet.
  • {TargetName}_N.png: static normal-map sprite sheet when Normal Map is enabled.
  • {TargetName}_{ClipName}.png: animation diffuse atlas.
  • {TargetName}_{ClipName}_N.png: animation normal-map atlas when Normal Map is enabled.

Pixelate does not create Unity .anim clips as a capture side effect. Use Unity's Animation window or your preferred sprite-animation workflow after the sprite sheet is generated.

8. Troubleshooting

Capture button is disabled: read the message in the Inspector. Pixelate blocks capture when required setup is missing or unsafe.
  • No capture camera assigned: assign a camera in the Camera section. Downstream capture sections stay hidden until setup is valid.
  • Animation needs an Animator: use Add Animator in the Animation section or add an Animator to the target manually.
  • Palette is ignored: custom palette textures must be 1 pixel tall, sRGB color, point-filtered, clamp-wrapped, uncompressed, and inside the Unity project. Use Fix import settings below the Custom Palette field when Pixelate shows an import warning.
  • Export folder changed or disappeared: Pixelate falls back to Assets/ so generated output stays inside the project.
  • Normal-map lighting looks flat: in URP, use a 2D Renderer, set Light Render Textures Render Scale to 1, use Sprite-Lit-Default, and enable Normal Maps on the Light2D.
